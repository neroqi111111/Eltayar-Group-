# Go-live checklist

- [ ] Supabase SQL migration applied successfully.
- [ ] Admin account created in Auth and added to `public.admin_users`.
- [ ] `SITE_ORIGIN` matches the published website origin exactly.
- [ ] Edge Function deployed and logs are clean.
- [ ] `assets/js/config.js` has the correct project URL and publishable/anon key.
- [ ] Test request is stored and visible only to an authorized admin.
- [ ] Test status update and confirm the new status persists after refresh.
- [ ] Test invalid email, short details, and missing consent.
- [ ] Test email fallback and mobile layout.
- [ ] Update privacy notice, business terms, prices, discount eligibility/deadline, and retention policy.
- [ ] Enable rate limiting/CAPTCHA and configure monitoring before marketing at scale.
